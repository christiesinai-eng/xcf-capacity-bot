# 🚀 Quick XCF Project Setup

## How to Use

Ask Claude Code: `Create a project folder for: XCF-XXXX | Project Name`

## What Happens Automatically ✅

1. **Google Drive folder** is created with the correct name and structure
2. **All subfolders** are created (including nested ones like 2.1_In Progress, 4.1_R1, etc.)
3. **Asana project** gets linked to the G Drive folder

**Time:** ~35 seconds

---

## One Manual Step Required ⚠️

After setup completes, you need to **add the link to Asana's "Key Resources" section**:

### How to (takes ~5 seconds):
1. Open your Asana project
2. Go to the **Overview** tab  
3. Find **"Key resources"** section (scroll down)
4. Click **"Add links & files"** button
5. Paste the **G Drive folder link** that was provided

## FAQ

**Q: Why isn't the link automatically in Key Resources?**  
A: Asana's API doesn't support this feature—it's UI-only. The link is in the project notes, but needs one manual step to appear in Key Resources.

**Q: Can I do the manual step later?**  
A: Yes! The link is already saved. You can add it to Key Resources anytime.

**Q: What if I forget to do the manual step?**  
A: No problem—folders are all set up. The manual step just makes the link more visible to your team in the Key Resources section.

**Q: Do I need to copy files from a template?**  
A: Not yet—folders are empty but ready. We're working on automating file copying.
